- Oyun: https://khalinta.github.io/dsim/ (iPhone'da Safari → Paylaş → Ana Ekrana Ekle)
- Proje planı ve ilerleme: [PROJE.md](PROJE.md)
- Çalışma kuralları ve teknik yapı: [CLAUDE.md](CLAUDE.md)
- İçerik biçimi: [icerik/BICIM.md](icerik/BICIM.md)

Bilgisayarda denemek için: `node araclar/sunucu.mjs`, sonra http://localhost:8080. Testler: `npm test`.
